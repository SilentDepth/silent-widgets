# 首页与配置器客户端导航

2026-10-26 追加实现，覆盖 `/` 和已知 widget 的 `/config` 路径。

## 实现

- `app/app.vue` 提供持久的应用根节点，渲染当前页面，并响应式更新标题、文档语言和 OG 信息。客户端与 SSR 使用同一结构。
- `app/navigation.ts` 复用 `loadPage()` 和已有动态导入，通过 History API 管理站内导航。只有首页和配置器加载该模块；未增加依赖。
- 首页目录和品牌链接保留真实 `href`。普通同源点击由事件委托接管；外链、下载、修饰键点击、其他 target 及独立 widget 页面保留浏览器行为。
- 工具选择器通过注入的导航接口切换配置器。每次页面切换递增页面 key，重新初始化字段、widget 和参数默认值；普通参数编辑不改变 key。
- 参数编辑通过导航接口更新当前 URL，并保留该条历史记录的标识。前进、后退重新读取目标 URL，恢复参数与滚动位置。显式刷新仍使用 SSR 并从 URL 初始化参数。
- 页面加载完成后才提交普通导航的 URL 和视图；加载期间保留旧页面，暂时禁用配置表单，根节点标记 `aria-busy`。请求序号使过期加载结果失效，避免覆盖最新导航。
- 页面切换后将焦点移至新页面标题。页内锚点不重建页面；异步资源加载失败时回退到浏览器页面请求。
