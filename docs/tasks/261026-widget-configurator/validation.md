# 实施与验收记录

日期：2026-10-26。分支：`feat/configurator`。

## 实施结果

五个 widget 已迁入 `app/widgets/`。每个目录的 `config.ts` 同时提供参数规则、默认值和元信息；Vue props 及参数类型从定义推导。首页只读取目录信息，独立页和配置器按需加载 widget。

`/` 提供 Notion 风格目录；`/<widget>` 使用通用全屏页面；`/<widget>/config` 使用原首页草稿的配置器布局。配置器直接挂载 widget，通过 props 更新预览。背景、语言和样式属于 widget，父页面提供查询容器和尺寸。

配置器支持字段校验、最近有效值预览、当前地址更新、默认值省略和手动复制回退。仓库更新使用 300 ms 防抖、AbortController 和请求序号，保留十分钟轮询和手动刷新。仅修改颜色或数字简写不会重新请求仓库。

验收时修正了以下问题：颜色色板现在可以从三位、四位、六位及八位十六进制颜色中提取 RGB；日历根据实际周数计算行数，避免部分起始日组合裁掉末行。颜色文本仍保留原始透明度。颜色数量超限时，表单显示完整原始值，允许用户直接修正。
